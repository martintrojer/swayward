# swayward documentation

Start with [Getting started](./Getting-Started.md). To learn the container
tree itself, read [Sway School](./Sway-School.md). The [configuration
introduction](./Configuration:-Introduction.md) links to the reference pages for
KDL configuration.

The documentation lives in `docs/wiki/` and builds with MkDocs:

```sh
cd docs
uv sync
uv run mkdocs serve
```

Large changes follow the compatibility contract in
[the foundation specification](https://github.com/martintrojer/swayward/blob/main/docs/specs/2026-09-12-swayward-foundation.md).
