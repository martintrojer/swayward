# Releasing swayward

swayward does not yet have a stable release process. Before the first release,
this page must define and verify:

- version numbering and changelog preparation;
- release build and slow-test commands;
- `swayward-ipc` package validation and publication;
- vendored dependency archives for distribution builders;
- annotated tags and GitHub release artifacts;
- package repository and announcement steps.

Do not copy niri's release checklist mechanically. swayward has different
package names, repositories, compatibility promises, and release gates.
