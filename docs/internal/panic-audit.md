## Cross-cutting proofs and decisions

- Tiling arena access: `check_node` enforces root presence/type, every child present, reciprocal parent links, unique reachability, and equal `children`/`percents` lengths. Every indexed mutation takes IDs from a current arena lookup/traversal or a just-completed allocation. The randomized operations call `check_invariants` after each generated mutation. These panics are corruption detectors, not client-validation branches; replacing all of them with logged partial mutation would preserve corrupt state and move the crash.
- Floating entries: explicit IDs enter through workspace membership checks; implicit IDs use `active_window_id`, and `FloatingLayout::verify_invariants` requires that ID in `entries`. Preset lists cannot be empty after `Layout::resolve` restores defaults.
- Parser bounds: command arguments are checked before indexing; string offsets come from `char_indices`, `find`, or UTF-8 character-length advancement. Current malformed input returns structured parser errors. The deferred parser task will replace mechanically unchecked syntax and add crate lints to prevent drift.
- Arithmetic: layout calculations use `f64`, validated finite percentages, guarded divisors, and clamping before integer sizing. IPC frame additions use the 16 MiB protocol cap and 4 MiB write-buffer cap. Stable IPC IDs deliberately use wrapping arithmetic. No untrusted integer operation in the census can overflow in debug/release with different control flow.

## Fixed before this pass

- Incomplete or out-of-order legacy event state no longer panics.
- Missing output geometry returns a structured command failure.
- Incoming client reply frames are capped before allocation.

## Deferred root-cause groups

- `review-panic-cross-component`: layout-to-window lookup, output snapshot lookup, and poisoned compositor mutexes. These need one recovery/logging policy rather than local catches.
- `review-ipc-parser-panics`: public serializer/parser checked access, oversized outgoing payload handling, and a crate-level lint gate.
